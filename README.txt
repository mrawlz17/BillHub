FlowMap v0.7.5
================

Purpose
-------
Adds a read-only Financial Audit under Plan so the forecast can be visually verified without changing financial data or calculation logic.

What changed
------------
- Plan now opens to Audit first: Audit | Goals | What If | Bills & Income.
- Audit exists only under Plan. There is no Home-screen link or reference to it.
- Choose any month in the live six-month forecast.
- Shows the same engine-derived starting/current balance, income, outflow, and ending balance.
- Separates Pending from Upcoming/remaining outflow.
- Shows the exact tie-out equation for the selected month.
- Lists every recurring bill occurrence and expected income occurrence generated by the active rules.
- Shows whether each occurrence is Upcoming, Pending, Skipped, Received/Cleared, overridden, or already absorbed into the current bank-balance checkpoint.
- Lists one-time/extra forecast items separately.
- Flags an unexplained missing recurring occurrence if one is ever detected.

Financial-integrity design
--------------------------
- The Audit screen is READ ONLY.
- finance-engine.js is unchanged from v0.7.4.
- No database migration.
- No new financial fields.
- No save, commit, clear, skip, edit, or record-creation action exists on the Audit screen.
- The month selector changes only an in-memory display variable; it is never persisted.
- Audit totals come from the same production monthBuckets/projectedItems engine used by the forecast. It is not a second calculator.

UPDATE INSTALL
--------------
If updating from FlowMap v0.7.4, replace the app files included in the Update ZIP in the root of the GitHub Pages repository. Do not delete or reset browser data.
